PROTECTED PDF QR PACKAGE

Included:
- document.pdf — your uploaded PDF
- index.html — protected-style browser viewer
- qr_code.png — QR code

IMPORTANT:
The QR currently points to:
https://YOUR-DOMAIN.example/protected-document/

After uploading this folder to a web host, replace the QR target with the real public
URL of the folder/page. The viewer hides normal PDF download/print controls and
blocks common save/print/context-menu shortcuts.

This is NOT absolute DRM. Anyone who can view a document can potentially screenshot,
screen-record, inspect network requests, or otherwise capture it. For stronger
protection, use authentication, expiring links, per-user watermarks, and a hosted
document viewer that keeps the original PDF behind access control.
